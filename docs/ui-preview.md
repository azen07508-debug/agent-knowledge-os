# 明理界面预览与回归

在 `mingli-split` 上，把原先输入表单和 JSON 双栏控制台改为参考图风格的移动界面：宋体、留白、柔光日签、竹影/奔马命盘卡、太阳/月亮切片和悬浮底部导航。保留八字、紫微、星座、问事和流月窗口的真实接口。

首次查看命盘先确认出生信息。1990-02-01 12:00 是明确标注的表单示例，不自动假定用户生日。出生信息默认只保留在当前页面；勾选“记住本机出生信息”才写入 localStorage，可在“我的”清除。访问密钥只用于当前页面请求，不新增持久保存。日签是生活札记，不是接口生成的运势。

## 运行

从仓库根目录运行：

```bash
.venv/bin/python -m uvicorn api.server:app --host 127.0.0.1 --port 8022
```

没有前端安装或打包步骤。`/` 返回页面，`/assets` 提供本地图片、图标、字体和 CSS。设置 `MINGLI_API_KEY` 时，静态界面仍能加载，计算接口仍需密钥。

## 浏览器回归

云环境已有 Node、Playwright 和 `/usr/bin/chromium`：

```bash
node tests/browser_ui.cjs
# 使用其他服务地址时：
MINGLI_UI_URL=http://127.0.0.1:8022 node tests/browser_ui.cjs
```

脚本需要未启用 API 密钥的本地服务，启动全新浏览器上下文，不使用个人数据。验证导航、五项真实计算、四柱、十二宫、太阳/月亮、仅日期星座交界、空白问题、收藏、出生信息选择性保存/清除、Esc 关闭面板、320/393 手机及 1440 桌面布局。检查页面 JS 错误、HTTP 错误、外部请求和卡片重叠，并保存截图到 `reports/ui/`。

视觉对照与检查结论见根目录 `design-qa.md`。
