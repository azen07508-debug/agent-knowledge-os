# 明理界面预览与回归

在 `mingli-split` 上，把原先输入表单和 JSON 双栏控制台改为参考图风格的移动界面：宋体、留白、柔光日签、竹影/奔马命盘卡、太阳/月亮切片和悬浮底部导航。保留八字、紫微、星座、问事和流月窗口的真实接口，并加入上升、整宫/等宫、十天体主要相位和交映解读。

首次查看命盘先确认出生信息。1990-02-01 12:00 是明确标注的表单示例，不自动假定用户生日。出生信息默认只保留在当前页面；勾选“记住本机出生信息”才写入 localStorage，可在“我的”清除。访问密钥只用于当前页面请求，不新增持久保存。日签是生活札记，不是接口生成的运势。

## 运行

从仓库根目录运行：

```bash
.venv/bin/python -m uvicorn api.server:app --host 0.0.0.0 --port 8023
```

没有前端安装或打包步骤。`/` 返回页面，`/assets` 提供本地图片、图标、字体和 CSS。设置 `MINGLI_API_KEY` 时，静态界面仍能加载，计算接口仍需密钥。

## 浏览器回归

云环境已有 Node、Playwright 和 `/usr/bin/chromium`：

```bash
node tests/browser_ui.cjs
# 使用其他服务地址时：
MINGLI_UI_URL=http://127.0.0.1:8023 node tests/browser_ui.cjs
MINGLI_UI_URL=http://127.0.0.1:8023 node tests/browser_extended.cjs
```

脚本需要未启用 API 密钥的本地服务，启动全新浏览器上下文，不使用个人数据。验证导航、五项真实计算、四柱、十二宫、太阳/月亮、仅日期星座交界、空白问题、收藏、出生信息选择性保存/清除、Esc 关闭面板、320/393 手机及 1440 桌面布局。检查页面 JS 错误、HTTP 错误、外部请求和卡片重叠，并保存截图到 `reports/ui/`。

视觉对照与检查结论见根目录 `design-qa.md`。

## 本次试用

服务启动后，使用环境的端口预览打开 8023（或者在运行服务的机器上访问对应 HTTP 地址）。这不是已部署的公开站点。

1. 底部点“命盘”，选择“完整星盘”。
2. 修改示例生日，填写准确出生时刻，选择出生城市（或手填经纬度），确认对应时区。
3. 选择整宫制或等宫制，确认并查看。结果页的上升/行星/宫位/相位按钮可跳到对应章节。
4. 修改结果页出生信息后会自动重新计算；“补充 / 修改出生信息”也会重算。
5. 返回“命盘”，选择“交映解读”，填写你想探索的问题，查看三套体系的事实和解释依据。

如果只知道日期，日月显示当天候选，其他精确结果不会补填。上升/宫位需要地点；城市中心坐标只是方便试用的近似值。跨体系说明是固定、可追溯的象征探索框架，不是 LLM 预测。

可使用示例 1990-02-01 12:00、上海，检查太阳水瓶、月亮白羊、上升金牛。示例不是用户本人的出生信息。
