# 本地部署常见错误

## 报错原文

EverOS 或 arbiter-lite 未安装时需要明确提示

## 解决方案

## 潜在 bug
- 依赖未安装时需要 fallback 或友好提示
- 文件名必须清理非法字符
## 安全风险
- 不写入 API Key、私钥、助记词或密码
- EverOS 默认只绑定 127.0.0.1
## 架构问题
- mock 与真实实现要保持接口一致，方便后续替换
## 是否可运行
当前 demo 不需要真实 API Key，应该可以本地运行。
## 改进建议
- 后续接入真实 LLM 前增加配置审计
- 对 EverOS 写入增加重试和脱敏检查
